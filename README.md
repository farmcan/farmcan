# Hi, I'm Can / 二四 👋

Farming Guy，持续耕耘代码与工具。关注 **Agent Runtime、AI 编程工具与 AI Infra**。

我在探索如何让 AI Agent 的工作更容易延续、协作和验证，把日常开发中遇到的问题做成可复用的工具。

### 关注方向

- **Agent Runtime & Orchestration**：任务拆分、多 Agent 协作、执行预算、测试与评审关卡。
- **Session Memory & Developer Tools**：会话搜索、回放、分叉，以及不同编程 Agent 之间的上下文迁移。
- **AI Infrastructure**：云原生系统、资源调度与 GPU 基础设施。

### 公开项目

| 项目 | 解决的问题 |
| --- | --- |
| [KAGE](https://github.com/farmcan/kage) | 为 Claude Code、Codex 和 Qoder 提供本地会话记忆：搜索、回放、分叉、跨工具迁移与任务派发。 |
